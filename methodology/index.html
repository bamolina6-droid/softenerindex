Editorial standards

Methodology

SoftenerIndex would rather ship an empty data box than a round number that sounds local. This page is the public version of the nightly frontmatter workflow in the repository README.

What may appear as a number

  • Hardness only with hardnessSource (name, URL, retrieved date). Grains per gallon and mg/L as CaCO₃ are optional fields; the schema refuses either without a source.
  • Installers only as rows with a name and a source. City pages staylistingStatus: research until that array is non-empty.
  • Prices are not a collection field. Guides talk about quote structure, not national or Phoenix averages we did not collect.

What will not appear

  • Converted adjectives (“very hard”) turned into grains.
  • Dealer counts inferred from ads or map pins.
  • Installed-cost ranges copied from other content farms.
  • Performance percentages for salt-free devices we did not test.

City pages

Phoenix ships first, linked to City of Phoenix water-quality materials and the Arizona Registrar of Contractors. Those links are starting points for the reader. They are not a substitute for pasting a hardness table into frontmatter without reading it.

Each city file has lastVerified. The nightly workflow updates that date even when nothing new is sourced, so “we looked” is visible and “we guessed” is not.

Corrections

If a sourced figure changes in a later utility report, replace the number, the URL if needed, and the retrieved date in the same commit. Do not leave a stale grain value with a fresh timestamp.
